# dreamcore · 主体曝光

把一张普通照片做成梦核那种「主体曝光」：主体被打成发光的白，背景留着天色或者染一层雾，再撒一层胶片颗粒。

仓库里不带示例图。

## 装

```bash
python3 -m venv .venv
.venv/bin/pip install numpy pillow "rembg[cpu]"
# 想用 --mode seg（认得出房子、树、天、草、水），再装：
.venv/bin/pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install transformers
```

第一次跑会自动下载模型（rembg 约 180 MB，SegFormer 约 250 MB），之后离线也能用。只要 CPU，一张两千像素的图十几秒到半分钟。

## 用

```bash
.venv/bin/python dream.py 输入.jpg 输出.jpg [色调] [选项]
```

**色调**（染背景用）：`blue` 雾蓝 · `lavender` 薰衣草 · `sakura` 樱粉 · `ember` 暖橘，默认 `lavender`。

**选项**

| 选项 | 作用 |
|---|---|
| `--mode auto` | 默认。先让 rembg 找主体；找不到像样的主体（风景照常见）就自动换成 `sky` |
| `--mode sky` | 天空反抠：亮的、偏蓝的算天，其余比天暗的枝杈、花、楼都算主体。**树枝对着天的照片用这个最好** |
| `--mode seg` | 语义分割：天、草、水、路、地算背景，房子、树、人、花……算主体。**有天有地、中间立着东西的照片用这个** |
| `--mode luma` | 全图处理：不分主体，整张按明暗翻，暗的打白、亮的留色。**满屏一样东西（一片林子）的照片用这个**，出来像下过雪 |
| `--true` | 背景尽量保留原来的颜色；不加就是淡淡的雾色 |
| `--keep 0.03` | 主体里留多少原图的明暗纹理，0 是纯白剪影，默认 0.12 |
| `--glow 1.8` | 光晕强度，默认 1；天被洗白太多就调小 |
| `--band 0.12` | 只在 `sky` 模式：天际线往下多深还算主体（占画高的比例）；树一直长到画面底的照片给 `0.9` |

## 哪种照片配哪种模式

- **枯枝、花枝对着天**：`--mode sky --band .9 --keep .03 --true`
- **夜里一根亮的树干、一个人、一朵花的特写**：默认 `auto`，`--keep .03 --glow 1.8`
- **一整片树林、一整面花墙**：`--mode luma`
- **风景：天、远处的楼和树、近处的草地和水**：`--mode seg --keep .03`

拿不准就几种都跑一遍，挑好看的。

## 它在做什么

1. **找主体**：按模式得到一张遮罩，白的地方是主体。
2. **背景**：去一点饱和、压一点对比，往色调里染；`--true` 时几乎不动原色。
3. **主体**：直接打白，按 `--keep` 留一丝原来的明暗当纹理。
4. **光晕**：遮罩糊开两层（一窄一宽）往背景上叠白；`sky` 模式下光只往天上晕，不糊到地上。
5. **颗粒**：一层亮度噪点加一层很淡的彩色噪点。
